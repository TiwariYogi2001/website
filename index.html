Pizza sales

MySQL

Revenue, peak hours, size mix and best sellers across a four-table order dataset.

-- Top 3 pizzas by revenue in each category
SELECT name, revenue
FROM (
  SELECT category, name, revenue,
         RANK() OVER (PARTITION BY category
                      ORDER BY revenue DESC) AS rn
  FROM (
    SELECT pt.category, pt.name,
           SUM(od.quantity * p.price) AS revenue
    FROM pizza_types pt
    JOIN pizzas p ON pt.pizza_type_id = p.pizza_type_id
    JOIN order_details od ON od.pizza_id = p.pizza_id
    GROUP BY pt.category, pt.name
  ) AS by_pizza
) AS ranked
WHERE rn <= 3;

Airbnb listings

PostgreSQL

Property mix, guest ratings and host engagement across listings, calendar and reviews.

-- Hosts with 2+ listings but a rating below 4.0
SELECT host_name,
       COUNT(*)                  AS total_listings,
       AVG(review_scores_rating) AS avg_rating
FROM listings
WHERE review_scores_rating IS NOT NULL
GROUP BY host_name
HAVING COUNT(*) >= 2
   AND AVG(review_scores_rating) < 4.0
ORDER BY avg_rating;

IPL performance

PostgreSQL

Win counts, scoring efficiency and bowling strength by team across seasons.

-- Run rate by team
SELECT team,
       SUM(runs_scored)  AS runs,
       SUM(overs_faced)  AS overs,
       ROUND(SUM(runs_scored)::numeric
             / SUM(overs_faced), 2) AS run_rate
FROM ipl
GROUP BY team
ORDER BY run_rate DESC;

Music store

SQL

Best customers, top cities and genre popularity by country from an 11-table store database.

-- Where should we hold a promotional festival?
-- The city whose customers spend the most.

       SUM(total) AS invoice_total
